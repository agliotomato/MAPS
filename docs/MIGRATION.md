# All_Agent → MAPS 이전

2026-10-16에 `C:\Users\skht0\All_Agent`의 필요한 파일을 `C:\Users\skht0\MAPS`로 복사했습니다. 원본 파일과 Git 이력, 실험 원문, 데이터베이스는 보존했습니다. MAPS에 이미 있던 커밋 없는 main 브랜치와 origin 설정을 사용합니다.

## 선택 기준

- 네 역할의 운영 소스, SQL 스키마, 수집/검색에 필요한 정적 설정.
- 독립 추론, 상호 검토, 원문·기업·기간·최종 검사.
- 핵심 회귀 검사와 필요한 작은 원문/응답 입력.
- 고정 입력 비교 어댑터, 현재 상태/한계와 비용 인계.

과거11,000개 이상의 실험 파일, 원래 `.git` 이력, 외부 참고 저장소, 중복 실행 스크립트, PDF, 자동 출력, DB/벡터/모델 캐시, 실제 비밀값은 새 Git에 넣지 않습니다. 이전 원본 폴더를 아카이브로 보관합니다.

## 실행 경계 정리

1. 운영에서 과거 벤치마크 모듈을 거쳐 읽던 역할 프롬프트를 `role_prompts.py`로 분리했습니다. 상수 내용은 원본과 동일합니다. 비교 어댑터의 JSON 직렬화/해시 함수도 같은 동작을 유지합니다.
2. 금융 주장/교차 검토 테스트가 과거 실행 폴더를 읽던 부분을 `tests/fixtures/financial.json`, `paired.json`으로 연결했습니다. 필요한 입력·분석·원최종을 그대로 추출하고 원본 파일 경로/해시는 명세에 기록했습니다. 실험 결과를 다시 생성하거나 덮어쓰지 않았습니다.
3. 반도체 설정의 특정 PC용 외부 인증파일 자동 탐색을 제거했습니다. `TIMESCALE_CREDENTIALS_PATH`를 명시하면 해당 파일을 로컬에서 읽습니다.
4. 기존 requirements의 `pyautogen` 대신 실제 사용 중인 `autogen-agentchat`/`autogen-ext` 버전을 명시했습니다. 기본 검증과 실제 DB/수집 의존성을 나눴습니다.

전체 원요청·응답·장부가 필요한 실험의 재실행기는 원래 아카이브에 남깁니다. 이 저장소의 비교 CLI는 오프라인 모의 검증입니다. 이전 경로에 의존하는 유료 실행기를 정상 작동하는 것으로 가져오지 않았습니다.

## 검증과 원본 추적

[이전 명세](migration_manifest.json)에 선택된 원본 파일의 SHA-256과 추출 입력의 출처를 기록합니다. 실제 이전 검증 결과·커밋 상태·다음 재개 조건은 [당일 보고서](../reports/graduation/DAILY_UPDATE_20261016.md)를 따릅니다.

`.env`와 데이터는 복사하지 않았습니다. 실제 분석을 재개할 때는 `.env.example`로 로컬 설정을 만들고 기존 외부 서비스를 명시적으로 연결합니다. 기존 데이터가 자동 복원되거나 새로 수집된 것으로 세지 않습니다.
